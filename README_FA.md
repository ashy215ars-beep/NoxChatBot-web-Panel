# پنل وب مدیریت NoxChat / عقرب

پنل مدیریتی Flask با رابط فارسی و راست‌چین برای دیتابیس SQLite ربات موجود.

## امکانات فعلی
- ورود مدیر با رمز عبور از متغیر محیطی
- داشبورد آمار از جدول‌های موجود `users`, `random_queue`, `conversations`
- جست‌وجوی کاربران و مسدودسازی/رفع مسدودی در جدول `users`
- ذخیره تنظیمات عمومی در جدول `admin_settings`
- فهرست کانال‌ها در `admin_channels`
- ارسال پیام همگانی به کاربران غیرمسدود (با تأیید دوم)
- سوابق تغییرات مدیریتی در `admin_audit`
- محافظت CSRF برای فرم‌های POST، کوکی HttpOnly و محدودیت اندازه درخواست

## نصب محلی
1. Python 3.10+ نصب باشد.
2. این پوشه را استخراج کن و داخل آن اجرا کن:
   ```bash
   python -m venv .venv
   ```
   ویندوز:
   ```powershell
   .venv\Scripts\activate
   ```
   لینوکس:
   ```bash
   source .venv/bin/activate
   ```
3. وابستگی را نصب کن:
   ```bash
   pip install -r requirements.txt
   ```
4. متغیرهای محیطی را تنظیم کن:
   - `NOXCHAT_ADMIN_PASSWORD`: رمز طولانی و قوی پنل
   - `NOXCHAT_WEB_SECRET`: مقدار تصادفی محرمانه برای نشست‌ها
   - `NOXCHAT_DB_PATH`: مسیر کامل همان فایل `bot_database.db` که ربات استفاده می‌کند
   - `NOXCHAT_BOT_TOKEN`: فقط اگر از ارسال همگانی استفاده می‌کنی؛ توکن را در کد/گیت/چت ننویس.
5. اجرا:
   ```bash
   python app.py
   ```
6. در حالت محلی باز کن: `http://127.0.0.1:5000`

## ویندوز (PowerShell) - نمونه تنظیم متغیرها
```powershell
$env:NOXCHAT_ADMIN_PASSWORD="یک-رمز-طولانی-و-منحصر-به-فرد"
$env:NOXCHAT_WEB_SECRET="یک-رشته-تصادفی-طولانی"
$env:NOXCHAT_DB_PATH="C:\مسیر\ربات\bot_database.db"
$env:NOXCHAT_BOT_TOKEN="توکن-جدید-ربات"
python app.py
```

## مهم: اتصال واقعی به ربات
این نسخه پنل را به همان فایل SQLite متصل می‌کند، اما تنظیمات قابل ویرایش در `admin_settings` و `admin_channels` فعلاً در خود کد بات خوانده نمی‌شوند. بنابراین:
- آمار و مدیریت مسدودی، اگر مسیر دیتابیس درست باشد، روی داده‌های واقعی اعمال می‌شوند.
- تغییر متن‌ها، زمان انتظار، فعال/غیرفعال کردن چت شانسی و فهرست کانال‌ها تا زمان افزودن خواندن تنظیمات از طرف کد بات، فقط ذخیره می‌شوند.
- برای اعمال فوری واقعی، باید کد بات تغییر کند تا این مقادیر را هنگام اجرا از دیتابیس بخواند. این یکپارچه‌سازی جداگانه است و بهتر است روی نسخه پشتیبان آزمایش شود.

## استقرار عمومی
- از سرور توسعه Flask استفاده نکن؛ از Gunicorn/Waitress یا سرویس WSGI مناسب استفاده کن.
- حتماً HTTPS، رمز قوی، فایروال و دسترسی محدود را تنظیم کن.
- مسیر دیتابیس باید دقیقاً فایل مشترک بات باشد و کاربر سیستم اجازه نوشتن داشته باشد.
- توکن افشاشده را در BotFather تعویض کن؛ فقط توکن جدید را به‌صورت متغیر محیطی امن تنظیم کن.
- فایل دیتابیس و پنل را در مخزن عمومی قرار نده.
- ارسال همگانی عملیات غیرقابل برگشت است؛ ابتدا با تعداد کم آزمایش کن.
